# Kaggle-Advertising-Data
📊 **Sales Prediction &amp; Marketing ROI Engine** — An interactive machine learning dashboard for sales forecasting, marketing-channel analysis, and budget optimization. The project benchmarks 7 regression models, identifies TV × Radio advertising synergy, and provides a real-time scenario simulator for predicting sales based on marketing spend.
